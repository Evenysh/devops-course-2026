# Git в VS Code vs терминал

Что удобно в VS Code:

1. Сразу видно, какие файлы изменились — не надо писать `git status`.
2. Diff цветной: зелёным добавленное, красным удалённое.
3. GitLens показывает автора строки, если навести курсор.

Что удобнее в терминале:

- Пушить и создавать ветки. В IDE легко нажать не ту кнопку, а команда в терминале понятнее.
