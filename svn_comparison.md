# Git vs SVN

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

В Git ветка — это просто указатель на коммит. Создать её можно за секунду, копировать все файлы не нужно.

В SVN ветка — это копия папки на сервере. На большое дерево файлов это долго и тяжело, поэтому ветки там делают реже.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет. SVN централизованный: коммит сразу уходит на один общий сервер. Без сети сервер недоступен, коммитить некуда.

В Git копия репозитория есть на компьютере, поэтому `git commit` работает офлайн. В интернет нужен только `git push`.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

- Старый проект уже на SVN, и переезд на Git дороже, чем поддержка как есть.
- Нужен один жёсткий сервер и простые права на папки (часто так в госсекторе и банках).
- Команда небольшая и почти не пользуется ветками — центральный сервер им привычнее.
